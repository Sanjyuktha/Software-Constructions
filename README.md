# Aarohi Music Playlist Batch Creator

## Project Link
https://aarohi-8lj7.vercel.app/

## About Project
Aarohi Music Playlist Batch Creator is a web-based application developed to create and manage music playlists efficiently in batches. The system helps users organize songs, generate playlists automatically, and manage music collections easily.

## Features
- Create playlists in batches
- Organize songs efficiently
- Easy playlist management
- User-friendly interface
- Fast music categorization

## Technologies Used
- HTML
- CSS
- JavaScript
- MongoDB
